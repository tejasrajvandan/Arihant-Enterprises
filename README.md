# Arihant Enterprises Static Website

## Folder structure

- `index.html` — website content and page structure
- `css/style.css` — website styles and responsive layout
- `js/script.js` — mobile navigation, footer year, and enquiry-form demo behavior
- `images/` — place any local images here if you later choose to replace external image URLs

## How to preview

1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.

The website currently uses external Unsplash images, Google Fonts, and Font Awesome CDN links, so an internet connection is needed for those resources to load. The enquiry form remains a front-end demo and does not send data until connected to an email service or backend.
